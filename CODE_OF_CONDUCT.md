# Code of Conduct

## Our standard

We want MediRAG to be a constructive technical project. Contributors are expected to be respectful, specific, and collaborative.

Unacceptable behavior includes harassment, personal attacks, discrimination, deliberate disruption, publishing private information, and other conduct that would make participation unsafe or hostile.

## Maintainer responsibility

Maintainers may remove comments, close issues, or reject contributions that violate this standard.

## Scope

This applies to project repositories, issues, pull requests, discussions, and other project spaces.
