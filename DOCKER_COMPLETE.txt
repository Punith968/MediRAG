   ✅ Multi-host orchestration

  2. bash scripts/docker-deploy.sh staging up
  3. Scale for testing: bash scripts/docker-deploy.sh staging scale backend 3
  4. Run tests and verify

Production Deployment (Docker Compose):
  1. Configure .env with production values
  2. bash scripts/docker-deploy.sh production up
  3. Setup monitoring: Access http://localhost:3001
  4. Verify health: bash scripts/docker-deploy.sh production health

Production Deployment (Docker Swarm):
  1. Initialize Swarm: docker swarm init
  2. Add worker nodes: docker swarm join --token <TOKEN> <MANAGER_IP>:2377
  3. Deploy: bash scripts/docker-swarm-deploy.sh medirag deploy
  4. Scale: bash scripts/docker-swarm-deploy.sh medirag scale backend 10
  5. Monitor: docker stack services medirag

GETTING STARTED IN 5 MINUTES
─────────────────────────────────────────────────────────────

Step 1: Navigate to production directory
  cd production

Step 2: Setup environment
  cp docker/.env.example .env
  # Edit .env with your API keys:
  # - PINECONE_API_KEY
  # - OPENROUTER_API_KEY
  # - DB_PASSWORD (change for production)

Step 3: Start all services
  bash scripts/docker-deploy.sh staging up

Step 4: Wait for services to be healthy (~30 seconds)
  bash scripts/docker-deploy.sh staging health

Step 5: Access services
  Frontend:   http://localhost:3000
  Backend:    http://localhost:8000
  Grafana:    http://localhost:3001 (admin/admin)
  Prometheus: http://localhost:9090

Done! All services running with full observability.

TROUBLESHOOTING
─────────────────────────────────────────────────────────────

Container won't start:
  bash scripts/docker-deploy.sh staging logs backend

Health check failed:
  bash scripts/docker-deploy.sh staging health

Database connection error:
  docker-compose -f docker/docker-compose.production.yml exec postgres \
    psql -U medirag -d medirag -c "SELECT 1"

Port already in use:
  Edit .env and change port numbers
  Or kill process: sudo lsof -i :8000

Out of disk space:
  docker system df
  docker system prune -a --volumes
